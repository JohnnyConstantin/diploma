# GopherKeeper

Клиент-серверная система для безопасного хранения приватной информации.

## Возможности

- Безопасное хранение логинов, паролей, текстовых данных, банковских карт, бинарных данных
- Быстрый и отзывчивый CLI интерфейс
- Метаинформация и теги для организации данных
- Синхронизация между клиентами

## Архитектура

Система состоит из:
- **Сервер** - REST API на Go, Postgres для хранения
- **Клиент** - CLI приложение с поддержкой основных функций

# GopherKeeper

GopherKeeper — это серверная часть менеджера паролей.  
Сервис отвечает за:

- регистрацию, авторизацию и аутентификацию пользователей;
- хранение приватных данных (логин/пароль, тексты, бинарные данные, банковские карты);
- шифрование пользовательских данных перед записью в БД;
- выдачу и синхронизацию данных для авторизованных клиентов.

---

# Ограничения

- Для работы клиентского приложения необходим доступ в интернет (к серверной части). Синхронизация поддерживается только для онлайн-клиентов
- Отправка бинарных данных ограничена 100MB

## Технологии

- **gin-gonic** — HTTP-сервер и роутинг.
- **PostgreSQL**, `pgxpool` — БД и пул соединений.
- **AES-GCM + base64** — шифрование пользовательских данных (логины/пароли, и т.п.).
- **JWT,cookies** — аутентификация и авторизация.
- **logrus** — структурированное логирование.

---

## Общая архитектура

Сервер - многослойная архитектура;
Клиент - стандартный HTTP-клиент;

- `server/main.go` - входная точка, сборка всех зависимостей.
- `internal/*` - бизнес-логика и HTTP-слой (auth, handlers, repositories).
- `pkg/*` - переиспользуемые инфраструктурные пакеты (config, db, logger, crypto).
- `migrations/*` - миграции бд
- `cmd/*` - реализация клиента и CLI интерфейса
